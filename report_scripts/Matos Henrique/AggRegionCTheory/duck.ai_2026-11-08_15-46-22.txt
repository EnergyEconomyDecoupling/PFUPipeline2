**Yes. You can find the common names with a few 0/1 indicator operations, and you never need to multiply A and B.** The approach is to turn each matrix into a pattern of zeros and non-zeros, then combine those patterns.

## The steps

Let N_A be the matrix with entries 1 where A is non-zero and 0 elsewhere, and define N_B the same way for B.

1. **Find the non-zero columns of A.** Compute u = (1ᵀ N_A)ᵀ, a vector of column counts. Column j is non-zero when u_j > 0.
2. **Find the non-zero rows of B.** Compute v = N_B 1, a vector of row counts. Row j is non-zero when v_j > 0.
3. **Find the common names.** Compute w = u ∘ v, the element-wise product. Because u and v are 0/1 vectors, this is an AND. Name j is common when w_j = 1.
4. **Find the rows of A that touch the common names.** Compute N_A w. Row i of A is in your answer when (N_A w)_i > 0.
5. **Find the columns of B that touch the common names.** Compute wᵀ N_B. Column k of B is in your answer when (wᵀ N_B)_k > 0.

The result is the set of row names of A from step 4 and the set of column names of B from step 5.

I'd avoid using A·B to test for zeros. Products of non-zero values can cancel to exactly zero, so the product can hide a real overlap. Counting 0/1 indicators never cancels, because all counts are non-negative.

## Worked example

Suppose the shared names are c1, c2, c3. Column c1 of A is (1, 0, 0), column c2 is all zeros, and column c3 is (0, 2, 0). Row c2 of B is (3, 0), and row c3 of B is (0, 4).

- Non-zero columns of A: c1, c3
- Non-zero rows of B: c2, c3
- Common: **c3**
- Rows of A with a non-zero in c3: **row 2**
- Columns of B with a non-zero in c3: **column 2**

## Code

In R:

```r
nzA <- A != 0
nzB <- B != 0
common <- intersect(colnames(A)[colSums(nzA) > 0],
                    rownames(B)[rowSums(nzB) > 0])
rowsOfA <- rownames(A)[rowSums(nzA[, common, drop = FALSE]) > 0]
colsOfB <- colnames(B)[colSums(nzB[common, , drop = FALSE]) > 0]
```

**Yes. Each triple is a nonzero entry of a 3-way indicator array T, built from the 0/1 pattern matrices.** For a row i of A, a common name c, and a column k of B, set T[i,c,k] = N_A[i,c] · N_B[c,k], restricted to common names c. The product is 1 only when A[i,c] ≠ 0 and B[c,k] ≠ 0, so the nonzero entries of T are exactly your triples.

The matrix M from before is the sum of T over the common-name axis: M = Σ_c T[:,c,:]. Keeping the c axis separate is what lets you recover the middle name for each triple.

In code, you take the outer product of column c of the A pattern with row c of the B pattern, for each common name c. In R:

```r
nzA <- A != 0
nzB <- B != 0
common <- intersect(colnames(A)[colSums(nzA) > 0],
                    rownames(B)[rowSums(nzB) > 0])
P <- nzA[, common, drop = FALSE]
Q <- nzB[common, , drop = FALSE]
T <- array(0, dim = c(nrow(P), length(common), ncol(Q)))
for (j in seq_along(common)) T[, j, ] <- outer(P[, j], Q[j, ])
idx <- which(T > 0, arr.ind = TRUE)
```

In Python with NumPy, the outer products become a single `einsum` call:

```python
nzA = A != 0
nzB = B != 0
common = [c for c in nzA.columns[nzA.any(axis=0)] if c in nzB.index[nzB.any(axis=1)]]
P = nzA[common].to_numpy(dtype=int)      # shape: rows of A × common
Q = nzB.loc[common].to_numpy(dtype=int)  # shape: common × columns of B
T = np.einsum('ic,ck->ick', P, Q)
triples = [(A.index[i], common[c], B.columns[k]) for i, c, k in np.argwhere(T)]
```

The number of triples can grow quickly, since each common name multiplies the rows of A that touch it by the columns of B that it touches. If your matrices are large or sparse, store them as sparse matrices and loop over common names instead of building the full 3D array.

**Yes, but you have to restrict the outer product to the common names and then filter out the mismatched pairs.** `outer(A, B)` on two matrices returns a 4D array with dimensions (rows of A, columns of A, rows of B, columns of B). Its entry [i, c, k, l] is A[i,c] · B[k,l], so it pairs every column of A with every row of B. You only want the pairs where the column name of A equals the row name of B, and that name is common. Keeping just those entries gives your triples.

Working with the 0/1 patterns and restricting to the common names:

```r
nzA <- A != 0
nzB <- B != 0
common <- intersect(colnames(A)[colSums(nzA) > 0],
                    rownames(B)[rowSums(nzB) > 0])
Ac <- nzA[, common, drop = FALSE]
Bc <- nzB[common, , drop = FALSE]

X <- outer(Ac, Bc)              # dims: rows of A, |common|, |common|, columns of B
keep <- which(X > 0, arr.ind = TRUE)
keep <- keep[keep[, 2] == keep[, 3], , drop = FALSE]   # keep only matching common names

triples <- data.frame(rowA = rownames(A)[keep[, 1]],
                      common = common[keep[, 2]],
                      colB = colnames(B)[keep[, 4]])
```

The filter `keep[, 2] == keep[, 3]` is what makes this work. Without it, you would get pairs that link a column of A to a row of B with a different name.

This approach is less efficient than the loop version. It builds the full array, which has size (rows of A) × |common|² × (columns of B), even though most of those entries are discarded. For large matrices, the loop over common names uses much less memory.
